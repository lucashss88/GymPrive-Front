# Gym Prive - Frontend 🏋️‍♂️

Este é o frontend do sistema Gym Prive, desenvolvido em **React.js**.

## 🚀 **Instalação e Configuração**
Siga os passos abaixo para configurar e rodar o frontend localmente.

### **1️⃣ Pré-requisitos**
Antes de começar, instale as seguintes dependências:
- [Node.js (LTS)](https://nodejs.org/)

### **2️⃣ Clonar o repositório**
```sh
git clone https://github.com/seu-usuario/GymPrive-Front.git
cd GymPrive-Front

⚙️ 2.2 Configuração das Variáveis de Ambiente
Crie um arquivo .env dentro da pasta gym-prive-frontend e adicione:
REACT_APP_API_URL=http://localhost:3001

📦 2.3 Instalar dependências
npm install

▶️ 2.4 Iniciar o frontend
npm start
O frontend estará rodando em http://localhost:3000.

🛠 Tecnologias Utilizadas
Frontend: React.js, Axios, React Router, Styled Components / Tailwind CSS

Agora o projeto está pronto para ser executado localmente! 🚀🔥
